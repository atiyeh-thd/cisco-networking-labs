Inter-VLAN Routing with Router-on-a-Stick – Cisco Packet Tracer

Designed and implemented an Inter-VLAN routing topology using the Router-on-a-Stick method in Cisco Packet Tracer.
The project demonstrates how a single router interface can be configured with multiple subinterfaces to enable communication between different VLANs.

**Key concepts:**
* VLANs
* 802.1Q trunking
* Router subinterfaces
* Inter-VLAN routing
* IP addressing
* Default gateways
* Connectivity troubleshooting
