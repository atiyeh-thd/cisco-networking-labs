# Inter-VLAN Routing with Router-on-a-Stick – Cisco Packet Tracer

## Overview
This project demonstrates Inter-VLAN routing using the Router-on-a-Stick method in Cisco Packet Tracer.
A single router interface is configured with multiple subinterfaces to enable communication between different VLANs.

## Key Concepts
* Inter-VLAN routing
* Router-on-a-Stick
* VLANs
* 802.1Q trunking
* Router subinterfaces
* Default gateways
* IP addressing
* Connectivity testing

## Network Topology
The network topology was designed and configured using Cisco Packet Tracer.

## Testing
Connectivity between hosts located in different VLANs was verified using ping tests and Cisco IOS verification commands.

* Cisco Packet Tracer
* Cisco Router
* Cisco Switch
