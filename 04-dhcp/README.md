Cisco DHCP Configuration Lab – Packet Tracer

Configured a DHCP-based network using Cisco devices in Packet Tracer to automatically assign IP addressing information to network hosts.
The project demonstrates DHCP pool configuration and the automatic distribution of network parameters to clients.

**Key concepts:**

* DHCP
* DHCP pools
* IP address allocation
* Default gateway configuration
* DNS configuration
* Cisco IOS configuration
* Connectivity testing
