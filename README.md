# Cisco Networking Labs

A collection of hands-on Cisco networking labs developed using **Cisco Packet Tracer** while studying computer networking and CCNA-related concepts.
This repository contains practical network configurations and topologies covering switching, routing, redundancy, and network troubleshooting.

## Labs
### 1. VLAN Configuration
Configuration of Virtual Local Area Networks (VLANs) for network segmentation and management of broadcast domains.
**Topics:** VLANs, Access Ports, Network Segmentation

### 2. Router-on-a-Stick
Implementation of Inter-VLAN routing using router subinterfaces and 802.1Q trunking.
**Topics:** Inter-VLAN Routing, Router-on-a-Stick, VLANs, Trunking

### 3. EtherChannel
Configuration of EtherChannel to combine multiple physical links into a single logical connection between switches.
**Topics:** EtherChannel, Port-channel, LACP, Link Aggregation, Redundancy

### 4. OSPF
Implementation of dynamic routing using Open Shortest Path First (OSPF) between multiple Cisco routers.
**Topics:** OSPF, Dynamic Routing, Routing Tables, Neighbor Relationships

### 5. HSRP
Implementation of gateway redundancy using Hot Standby Router Protocol (HSRP) to improve network availability.
**Topics:** HSRP, First Hop Redundancy, Virtual IP, Active/Standby Routers, Failover
