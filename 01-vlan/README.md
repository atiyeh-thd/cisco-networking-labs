VLAN Configuration and Network Segmentation – Cisco Packet Tracer

Designed and configured a VLAN-based network using Cisco Packet Tracer.
The project demonstrates network segmentation using multiple VLANs and the configuration of Cisco switches for communication within separate broadcast domains.

**Key concepts:**
* VLAN configuration
* Access ports
* VLAN assignment
* Network segmentation
* Switch configuration
* Connectivity testing
