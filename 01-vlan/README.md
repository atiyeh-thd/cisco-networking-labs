# VLAN Configuration and Network Segmentation – Cisco Packet Tracer

## Overview
This project demonstrates the configuration and implementation of Virtual Local Area Networks (VLANs) using Cisco Packet Tracer.
The network is divided into multiple VLANs to logically separate devices into different broadcast domains and improve network organization.

## Key Concepts
* VLAN configuration
* Network segmentation
* Access ports
* VLAN assignment
* Broadcast domains
* Cisco IOS configuration
* Connectivity testing

## Network Topology
The topology was designed and configured using Cisco Packet Tracer.

## Testing
Connectivity between devices within the same VLAN was tested using ping and other network verification commands.

## Technologies
* Cisco Packet Tracer
* Cisco Switches
* VLAN
* IPv4
* Cisco IOS
